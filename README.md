Portfólio oficial de projetos web desenvolvidos pela **WD DEV**, marca de desenvolvimento de Wanderson Carlos. Este repositório reúne sites institucionais, vitrines digitais e experiências de comércio eletrônico criadas para tirar ideias do papel e colocá-las **ON**.

| Projeto | Finalidade | Demonstração |

## Tecnologias utilizadas

- **HTML5** — estrutura semântica e páginas institucionais
- **CSS3** — identidade visual, layouts responsivos e temas
- **JavaScript** — interatividade, catálogos, carrinhos e painéis demonstrativos
- **Motion.js** — animações suaves com respeito a `prefers-reduced-motion`
- **Web Storage API** — persistência local de preferências e dados de demonstração
- **Netlify** — hospedagem, configuração de deploy, redirects e headers
- **Git e GitHub** — versionamento e organização do código

## Destaques por projeto

### Belshi Studio

Experiência editorial premium para apresentar fotografia, design, história da marca, serviços, fundador e contato. Inclui Motion.js, políticas de privacidade e cookies, consentimento granular e configuração para Netlify.

### PH STORE

Loja responsiva com catálogo, filtros, sacola persistida no navegador, finalização via WhatsApp, Motion.js, banner de cookies, elementos de LGPD e configuração de segurança para Netlify.

### Marcell Celular

Vitrine digital completa com catálogo de smartphones, páginas de produto, modo claro/escuro, contas e painel administrativo demonstrativos, cálculo de frete preparado, Motion.js, cookies, páginas de LGPD e configurações de segurança.

### Marlon Tech

Conceito premium de e-commerce para eletrônicos, com catálogo de produtos novos e seminovos, carrinho, cadastro e login locais, gestão demonstrativa de estoque, painel administrativo, Motion.js, cookies e privacidade.

## Aviso sobre as demonstrações

Os projetos desta coleção são versões demonstrativas executadas sem backend de produção. Dados de contas, estoque, carrinho e painel podem ser armazenados apenas no navegador. Credenciais exibidas no código são exclusivamente de demonstração.

Para uso comercial real, autenticação, pagamentos, banco de dados, upload de imagens e controle administrativo devem ser conectados a um backend seguro.
